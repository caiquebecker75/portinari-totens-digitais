# Totens digitais Portinari

Proposta técnico-comercial da 75 LAB para a NEOBAND: telas, tecnologia embarcada, gestão remota de mídia, experiência touch, três cenários, investimento e cronograma dos totens digitais Portinari.

- No ar: https://projetos.75lab.com.br/portinari-totens-digitais/
- Fonte em `src/` (head.html, comp.css, slides/NN.html, app.js, assets/*.txt em base64)
- Montar: `python3 build.py` gera `index.html` (trava se sobrar token, se aparecer travessão ou se a contagem de telas mudar)
- Números de cenário, investimento e cronograma ficam no `src/app.js` (constantes `SC`, `GT`, `OX`)
